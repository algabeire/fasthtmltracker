# Ledger budget tracker

A polished FastHTML budget dashboard with seeded monthly financial data, responsive layout, budget progress, cash-flow visualization, recent activity, and an add-transaction modal.

## Run

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

Open http://localhost:5001 in your browser.
